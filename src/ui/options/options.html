Aspida

All checks run on this device. Nothing you browse, read or receive is sent anywhere.

Features

Each feature can be switched off on its own. Changes apply right away, without reloading pages.

Threat feeds

Feed files are downloaded from the listed hosts and matched locally. Your URLs are never sent to them.
