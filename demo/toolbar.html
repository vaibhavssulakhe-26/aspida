Toolbar icon demo

Aspida colours its toolbar icon from a local check of the page you are on. Pin the extension (puzzle-piece menu → pin) so the icon is visible. Every "site" below is a *.localhost name: Chrome sends those to this computer, so this same demo server answers and nothing leaves your machine. The checker still sees the lookalike name.

Open each link in this tab and watch the icon

  • localhost: green, "No known threats found for this site"
  • amazon-deals.localhost: orange, "Suspicious" (brand name on an unrelated domain)
  • paypa1.localhost: the warning page opens first (High risk); click "Proceed anyway" and the icon turns red
  • Normal (black) icon: open a new tab, the Aspida settings page or any non-web page, or turn off "Toolbar icon reflects the current site".
